五种手势，各有分工

不用记快捷键，鼠标一个动作就够

单击

平滑翻过一整屏（默认 80%）；快速连点会连续加速，点几下翻几屏。

单击 = 翻一屏 · 连点 = 越点越快
按住不放

像握住滚动条一样匀速滚动，松开或移开立即停下。

按住 = 持续滚动 · 松开即停
右键单击

点页面上的「上」按钮 → 一口气滚到最上；「下」按钮 → 滚到最下。

右键 = 直达顶部 / 底部
Ctrl + 按住拖动

把按钮拖到任何顺手的位置，松开即记住。

任意位置 · 松手即保存
中键单击

鼠标中键（按下滚轮）点上/下按钮 → 直接关闭当前标签页。

中键 = 关闭标签页 · 可在设置中关闭
闲置几秒自动变淡全屏时自动隐藏设置即时生效，无需刷新
