# 滚动按钮（Edge 扩展）

页面悬浮「上 / 下」两个圆形按钮：

- **左键单击**：平滑翻页 —— 默认滚动一屏高度的 80%，可在设置中调整（10%–100%）；快速连点会自动接力累加（点 3 下 = 翻 3 页），且连点积累越多滑动越快
- **左键按住不放**：连续匀速滚动（像按住滚动条一样）—— 默认 700 像素/秒，可调（200–3000）
- **松开 / 鼠标移出按钮 / 切走窗口**：立即停止
- **Ctrl + 左键按住拖动**：随时调整按钮在页面上的位置，松手即保存
- **右键单击按钮**：上按钮 → 直接滚到页面最上；下按钮 → 滚到页面最下
- **中键（按下滚轮）单击按钮**：直接关闭当前标签页（按下即触发；不需要时可在设置里关闭）
- **按网站排除**：默认所有网站都显示按钮；点扩展图标弹出菜单，可一键在当前网站禁用（设置页可手动增删排除域名，含子域名）
- **36 款样式 · 6 大分类**：纯色、渐变、玻璃、呼吸（呼吸灯脉动）、流光（流光移动）、金属 —— 每类 6 款，另有圆形 / 圆角两种形状
- **设置备份**：一键导出 / 导入设置文件（样式、位置、速度、排除名单），换电脑、重装浏览器随时恢复
- **内置教程**：第一次安装会自动打开 1 分钟用法教程；之后随时可从扩展菜单或设置页打开

## 安装（一次性，约 1 分钟）

1. 打开 Edge，地址栏输入 `edge://extensions` 回车
2. 打开左下角「**开发人员模式**」开关
3. 点「**加载解压缩的扩展**」，选择本文件夹（`edge-scroll-buttons`）

装好后，所有网页会出现两个圆形按钮。

## 设置

点 Edge 工具栏的扩展图标，弹出菜单：**「设置」**打开设置页；**「当前网站」开关**可一键禁用 / 启用该网站的按钮（关闭后该网站不再显示按钮，点击设置里的列表可管理）。

设置页里可以调整：

| 设置项 | 说明 | 默认 |
|---|---|---|
| 按钮样式 | 36 款：纯色 / 渐变 / 玻璃 / 呼吸 / 流光 / 金属（每类 6 款） | 经典深灰 |
| 按钮形状 | 圆形 / 圆角 | 圆形 |
| 按钮位置 | 在示意页面里点击 / 拖动圆点精确定位；也可在网页上 Ctrl+左键按住按钮拖动 | 右侧中部 |
| 按钮大小 | 40–160 px | 52 px |
| 按钮透明度 | 30%–100% | 70% |
| 翻页幅度 | 单击时滚动一屏的百分比 | 80% |
| 翻页速度 | 左键单击翻页的滑动快慢 | 1.0 × |
| 到顶/到底速度 | 右键单击滚到最上 / 最下时的滑动快慢 | 1.0 × |
| 按住速度 | 按住时每秒滚动像素数 | 700 px/秒 |
| 长按启动延时 | 按住多久后开始连续滚动 | 200 ms |
| 中键关闭标签 | 中键（滚轮键）单击按钮：关闭当前标签页 | 开 |
| 显示按钮 | 总开关（设置页顶部醒目卡片） | 开 |
| 网站排除 | 列表中的网站（含子域名）不显示按钮；支持粘贴完整网址自动识别域名 | 空 |
| 备份与恢复 | 导出 / 导入设置文件（样式、位置、速度、排除名单） | — |

设置自动保存，立即对所有已打开的网页生效，无需刷新。

设置只保存在本机浏览器里（**不会**随 Edge 账号自动同步）；换电脑 / 重装浏览器前，到「备份与恢复」导出一份文件，之后导入即可恢复。

## 已知边界

- Edge 内置 PDF 阅读器、`edge://` 系统页、扩展商店页不显示按钮（浏览器安全限制，任何扩展都如此）
- 极少数使用特殊内部滚动容器的页面若按钮不起作用，把网址发给维护者单独适配

## 更新 / 维护

修改代码后，到 `edge://extensions` 点本扩展卡片上的「刷新」（重新加载）按钮即可生效。
