1 分钟学会「滚动按钮」

网页右侧那两个小圆钮就是它 —— 下面是全部用法，看完直接去网页上试（动画可循环观看）。

单击 = 翻一屏

点一下，平滑翻过整屏（默认 80%）。快速连点会自动加速，点几下翻几屏。

按住 = 连续滚

按住不放，像握住滚动条一样匀速滚动；松开或鼠标移开立即停下。

右键单击 = 到顶 / 到底

右键点上按钮 → 一口气滚到页面最上；右键点下按钮 → 直接到最下。

Ctrl + 拖动 = 挪位置

按住 Ctrl 键、用左键把按钮拖到任何顺手的位置，松手即保存。

中键 = 关闭标签页

鼠标中键（按下滚轮）单击上/下任意按钮 → 直接关闭当前标签页；不想要时可在设置里关掉。

还有几个贴心设计

闲置自动变淡

鼠标离开几秒后，按钮自动变淡、不挡视线；鼠标靠近立即恢复。

全屏自动隐藏

看视频、做演示进入全屏时，按钮自动退场，不打扰你。

按网站排除

点扩展图标 → 一键禁用当前网站；名单在设置页管理（支持整个域名）。

想要更好看？

设置页里有 36 款样式（纯色 / 渐变 / 玻璃 / 呼吸 / 流光 / 金属）、圆形与圆角两种形状，还能调整翻页幅度与各段速度。换电脑或重装浏览器前，记得在「备份与恢复」里导出一份设置文件。
